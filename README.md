# LATTAFA RUSSIA — веб-магазин starter

Это стартовый Next.js-проект, подготовленный для дальнейшей настройки и публикации.

## Что включено
- Адаптивный сайт в чёрно-золотом стиле.
- Каталог и фильтры по 8 брендам.
- Корзина и форма оформления заказа.
- Административный интерфейс с входом через Supabase Auth.
- Управление товарами и заказами на уровне UI.
- SQL-схема для товаров, заказов и позиций заказа.
- Поддержка загрузки фотографий в Supabase Storage после настройки bucket и политик.

## Честно о готовности
Проект **не опубликован в интернете** и не является готовой платёжной системой. Для работы с реальной базой необходимо настроить Supabase, переменные окружения и политики безопасности. SQL намеренно не открывает публичную запись заказов и не разрешает любому вошедшему пользователю менять каталог. До публикации требуется серверный checkout, проверка цены и остатков на сервере, роли администраторов, защита от спама, юридические страницы и подключение платёжного провайдера.

## Запуск
Требуется компьютер или облачная среда разработки с Node.js 20+.

1. Установите зависимости: `npm install`
2. Скопируйте `.env.example` в `.env.local` и заполните значения из Supabase Project Settings → API.
3. Выполните `supabase/schema.sql` в Supabase SQL Editor.
4. Создайте в Supabase Storage bucket `product-images` и настройте политики чтения/загрузки.
5. Создайте пользователя администратора в Supabase Auth.
6. Настройте серверные роли и RLS-политики перед использованием административных изменений.
7. Запустите `npm run dev`.

## Supabase
- Создайте проект на https://supabase.com
- Никогда не вставляйте service-role key в клиентский код.
- Публичный anon key можно использовать только при правильно настроенном RLS.
- Не включайте публичную запись заказов без серверной проверки.

## Публикация
Проект можно разместить на https://vercel.com после подключения Git-репозитория и переменных окружения. Домен `lattafarussia.ru` нужно отдельно проверить и приобрести у регистратора; он не зарегистрирован автоматически.

## Платежи и доставка
Пока не подключены. Для реального приёма оплаты выберите провайдера, который поддерживает юридическую форму и страну регистрации продавца, настройте server-side создание платежа и проверку webhook-подписей. Не подтверждайте оплату по скриншоту или клиентскому запросу. Службу доставки нужно подключать отдельно.
